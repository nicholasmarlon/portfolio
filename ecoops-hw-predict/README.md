# EcoOps: Hardware & Battery Telemetry Predictive Analytics

> **EcoOps** is an end-to-end data analytics and predictive maintenance platform designed to monitor device health, battery telemetry, and remaining useful life (RUL), integrating ESG metrics and FinOps cost visibility.

---

## Project Overview

- **Operational Analytics:** Tracks device telemetry, health indices, and anomaly detection.
- **Predictive Maintenance (RUL):** Uses data models to forecast battery degradation and failures.
- **ESG & FinOps:** Monitors energy consumption, carbon footprint, and operational costs.

---

## Tech Stack

- **Language:** Python 3
- **App Framework:** Streamlit
- **Data Processing:** Pandas, NumPy
- **Database & Logging:** SQLite, Security Audit Logs

---

## How to Run Locally

1. Install dependencies: `pip install -r requirements.txt`
2. Run application: `streamlit run app.py`
